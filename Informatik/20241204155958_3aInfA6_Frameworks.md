## Lösung
### Überblick Frameworks
- Was ist ein Framework/wozu verwendet man es?
	- Liefert ein Grundgerüst, das vorgibt wie die Elemente miteinander interagieren. Das Framework gibt den grundlegenden "Flow" der Logik vor.
	- Erleichtert Trennung/Umsetzung von MVC-Konzepten
- Vorteile
	- Vereinfacht die Entwicklung
	- Macht Code sicherer
	- Ermöglicht Verwendung vorgefertigter Elemente
	- Viel Info bei Problemen in onlineforen
- Nachteile:
	- Einarbeitung dauert lange
	- viel Overhead
		- viel Code der gar nicht gebraucht wird

### Node.js
- Node.js ist kein Framework
- Node.js ist eine Laufzeitumgebung für Javascript
	- ähnlich wie die Java Runtime Environment (JRE) für Java
- Führt (Serverseitig) Javascript über V8-Engine für den Browser aus
- Funktionalität durch Node Package Manager (npm) leicht steuer- und erweiterbar
- Kann verwendet werden um A
