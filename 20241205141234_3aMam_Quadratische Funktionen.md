## Quadratische Funktionen
### allgemeine Form
$$f(x)=y=ax^2+bx+c$$
### Normparabel
$$f(x)=x^2$$
- Sei:
	- a=1
	- b=0
	- c=0

| a       | Effekt                                                      |
| ------- | ----------------------------------------------------------- |
| a<0     | Öffnung nach unten                                          |
| a>0     | Öffnung nach oben                                           |
| a=0     | keine Öffnung (und auch keine Quadratische Funktion)        |
| \|a\|<1 | fkt ist flacher "breiter" als Normparabel                   |
| \|a\|>1 | fkt ist steiler "flacher" als Normparabel                   |
| \|a\|=1 | fkt ist normparabel oder an x-Achse gespiegelte Normparabel |
### Sonderform b=0
$$f(x)=ax^2+c$$

| c   | Effekt                               |
| --- | ------------------------------------ |
| c<0 | Verschiebung der Funktion nach unten |
| c>0 | Verschiebung der Funktion nach oben  |


### Parabelform
$$f(x)=a(x+b)^2+c$$
