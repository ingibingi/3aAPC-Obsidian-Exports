# Kreis
Entsteht wenn eine Ebene einen Kreiskegel parallel zur Grundfläche schneidet
Kann (in einer Ebene) definiert werden durch:
- 1 Kreismittelpunkt M
- 1 Radius r
Die Menge der Punkte S einer Ebene R^2 für die gilt: 
- Der Abstand zum Punkt M = Radius r
# Ellipse
Entsteht wenn eine "flache" Ebene einen Kreiskegel schneidet
Kann (in einer Ebene) definiert werden durch:
- 2 Fokuspunkte F1, F2
- 1 Konstante (Länge) 2a
Die Menge der Punkte S einer Ebene R^2 für die gilt: 
- Die Summe der Längen F1S + F2S = 2a
# Parabel
Entsteht wenn eine Ebene die Parallel zur Mantelfläche ist einen Kreiskegel schneidet
Kann (in einer Ebene) definiert werden durch:
- 1 Leitlinie L
- 1 Fokuspunkt F
Die Menge der Punkte S einer Ebene R^2 für die gilt: 
- Der Abstand zur Leitlinie SL = Der Abstand zum Fokuspunkt SF
# Hyperbel
Entsteht wenn eine "steile" Ebene einen Kreiskegel schneidet
Kann (in einer Ebene) definiert werden durch:
- 2 Fokuspunkte F1, F2
- 1 Konstante (Länge) 2a
Die Menge der Punkte S einer Ebene R^2 für die gilt:
- Die Differenz der Längen F1S - F2S = 2a
