# Varianten
## Sign & Magnitude
- Wie normale Binärzahlen
- Most significant Bit zeigt Vorzeichen an (am weitesten links)
	- 0 ... positiv
	- 1 ... negativ
- Hat 2 Nullwerte
	- 0000 ... +0
	- 1000 ... -0

### Beispiel

| Dec | 4 Bit | 8 Bit     | Notiz                            |
| --- | ----- | --------- | -------------------------------- |
| 5   | 0101  | 0000 0101 |                                  |
| -5  | 1101  | 1000 0101 |                                  |
| 0   | 0000  | 0000 0000 |                                  |
| -0  | 1000  | 1000 0000 | Existenz kann Fehler verursachen |
| 7   | 0111  |           | Max-Wert für 4 Bit               |
| -7  | 1111  |           | Min-Wert für 4 Bit               |
### Vorteile
- Leicht verständlich für Menschen
### Nachteile
- Zwei Werte für 0
	- Einer davon für -0
- Algorithmus für Addition ist sehr umständlich
- Hat einen Wert weniger als mit der Anzahl der Bits möglich wäre.
## 1s Complement
- Positive Zahl nehmen und jedes Bit "flippen"
	- -> Negative Zahl
	- Übertrag aus Vorzeichen-Bit herausnehmen
		- und bei least significant Bit (rechtes Bit) neu hinzu addieren
### Beispiel

| Dec | 4 Bit | 8 Bit     | Notiz                            |
| --- | ----- | --------- | -------------------------------- |
| 5   | 0101  | 0000 0101 |                                  |
| -5  | 1010  | 1111 1010 |                                  |
| 7   | 0111  | 0000 0111 | Max-Wert für 4 bit               |
| -7  | 1000  | 1111 1000 | Min-Wert für 4 bit               |
| 0   | 0000  | 0000 0000 |                                  |
| -0  | 1111  | 1111 1111 | Existenz kann Fehler verursachen |
### Vorteile
- Algorithmus ist simpler als [Sign & Magnitude](#Sign%20&%20Magnitude)
### Nachteile
- Zwei Werte für 0

## 2s Complement
- Alle Bits flippen
- +1 addieren
- Überträge beim addieren werden ignoriert
### Beispiel

| Dec | 4 Bit | 8 Bit     | Notiz              |
| --- | ----- | --------- | ------------------ |
| 5   | 0101  | 0000 0101 |                    |
| -5  | 1011  | 1111 1011 |                    |
| 7   | 0111  | 0000 0111 | Max Wert für 4 Bit |
| -7  | 1001  | 1111 1001 |                    |
| 8   | -     | 0000 1000 |                    |
| -8  | 1000  | 1111 1000 | Min Wert für 4 Bit |
### Vorteile
- Simpler Algorithmus für Addition
- Hat nur einen Wert für 0
### Nachteile
- Logik dahinter ist etwas komplizierter
- Umwandlung im Kopf etwas komplizierter
